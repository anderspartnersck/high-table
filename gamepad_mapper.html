Still nothing after pressing a button?
  1. Click this page first (the browser only sees a pad while the tab is focused), then press a face button.
  2. Use Chrome — it has the widest controller support on macOS. (Safari/Firefox can be flaky.)
  3. Put the pad in a mode macOS recognizes: 8BitDo → any of X-input (START+X), D-input (START+B), or Switch (START+Y) — the mapper works in any of them. Mayflash F300 → an X-input PC mode. Re-plug after switching.
  4. Wired USB is the surest; for Bluetooth, re-pair so macOS lists it under Game Controllers.
  5. The DIAGNOSTICS line above shows what the browser reports — if it stays "0 slots seen" after a press, the browser isn't getting the pad (mode/cable/browser), not a mapper bug.
